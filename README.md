# AI Recruitment Automation – Customer Assistant

An n8n-based recruitment automation workflow designed to streamline candidate communication and HR-related messaging using workflow automation, Google Sheets, conditional logic, and email/message automation.

## 📌 Project Overview

This project demonstrates how workflow automation can be used to support recruitment and HR processes by connecting candidate information stored in Google Sheets with automated communication and decision-making steps.

The workflow reduces repetitive manual communication by automatically processing information and routing messages based on predefined conditions.

## 🎯 Business Problem

Recruitment teams often spend significant time performing repetitive administrative tasks such as:

- Processing candidate information
- Preparing recruitment-related messages
- Sending candidate communications
- Determining which communication path should be followed
- Managing repetitive HR communication

This workflow demonstrates how these tasks can be automated using n8n.

## ⚙️ Workflow

The automation follows this general process:

Google Sheets
↓
Data Processing
↓
Automated Message
↓
HR Message
↓
Conditional Logic
↓
Communication Routing
↓
Email / Message Output

## 🔧 Technologies & Tools

- **n8n** – Workflow automation
- **Google Sheets** – Data source and workflow trigger
- **Gmail / Email** – Automated communication
- **Conditional Logic (IF)** – Decision-making and routing
- **Automated Messaging** – Candidate/HR communication

## 🔄 Key Workflow Components

### 1. Google Sheets Trigger

The workflow uses Google Sheets as the starting point for the automation.

This allows information in the recruitment workflow to trigger the next steps automatically.

### 2. Data Processing

The incoming information is processed and prepared before being passed to the communication steps.

### 3. Automated Messaging

The workflow contains automated messaging steps designed to handle recruitment-related communication.

### 4. HR Message

An HR-specific messaging step is included to support communication within the recruitment process.

### 5. Conditional Logic

An IF node evaluates the information and determines which path the workflow should follow.

This allows different communication outcomes to be handled automatically.

### 6. Communication Routing

Depending on the result of the conditional logic, the workflow routes the information to the appropriate communication output.
